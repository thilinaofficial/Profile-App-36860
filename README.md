# Profile Details App

Mini Project 01 - SE303.3 Mobile Application Development (NSBM Green University)

A simple Flutter app that shows a user's profile (picture, name, email and points).
The floating **+** button adds 1 point each time it is pressed.

## Features
- App bar with the title "My Profile"
- Profile picture, name and email
- Points counter updated with `setState`

## How to run
```
flutter create . --platforms=android,ios,web
flutter pub get
flutter run
```
